# Dashboard para loja de vendas de vinyl
Projeto fictício em Excel elaborado para simular um dashboard a partir de uma base de dados em formato .xlsx, mostrando o resumo das venda de uma loja de vinyl no ano de 2025.

## Além disso, seria possível acrescentar no projeto cenários com possíveis propostas de melhorias para os próximos 6 meses.

> ## Cenários de Projeção (Próximos 6 Meses)


- 1 📉 Queda de 20% nas vendas	R$ X × 0,80	15% do novo valor	9%	Calculado

- 2 📈 Aumento de 20% nas vendas	R$ X × 1,20	15% do novo valor	9%	Calculado

- 3 ➖ Manutenção do faturamento	R$ X	15% do valor	9%	Calculado

##### *Onde R$ X é o faturamento bruto atual calculado a partir da base.* 



> ## 💡Sugestões de Melhoria por Cenário

***📉 Queda de 20%***

 - Criar promoções temáticas (ex: “Mês do Rock Clássico”)

- Reduzir custos variáveis com renegociação de fornecedores

- Investir em canais digitais com baixo custo (Instagram, WhatsApp)

***📈 Aumento de 20%***

 - Expandir mix de produtos (edições raras, acessórios)

- Fidelizar clientes com programa de pontos

- Aumentar presença em marketplaces e eventos de música

***➖ Faturamento Estável***

- Monitorar KPIs mensalmente

- Testar campanhas segmentadas por faixa etária

- Investir em parcerias com bares e casas de show
